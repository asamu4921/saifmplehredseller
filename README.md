# Landing Page Reseller RedDoorz

Satu file HTML + Tailwind CDN untuk landing page mobile-first yang fokus ke CTA WhatsApp.

## Cara pakai

Buka `index.html` di browser, atau jalankan dengan Live Server dari VS Code.

## Fitur

- Popup promo diskon hingga 28%
- CTA utama: lebih murah, pesan sekarang
- Tombol WhatsApp mengarah langsung ke nomor yang disediakan
- Layout modern, eye-catching, dan mobile-oriented
